# Sanjukta Deshpande — Personal Portfolio

A matrix-themed, responsive personal portfolio built for the Full Stack Development course - Assignment-1.

## Features
- Semantic HTML5 structure — Home, About, Education, Skills, Projects, Contact
- Responsive, mobile-first layout using CSS Flexbox/Grid + media queries
- Bootstrap components — navbar, cards, buttons, forms
- Animated matrix "digital rain" canvas background + terminal boot-sequence intro
- Interactive project filtering by category (backend / ml / fullstack)
- Clickable skill ↔ project cross-linking with smooth scroll
- Client-side contact form validation with dynamic success/error messages

## 🛠️ Tech Stack
- HTML5, CSS3 (custom properties, Flexbox/Grid)
- Bootstrap 5.3
- Vanilla JavaScript (ES6+)
- Google Fonts (JetBrains Mono)

## 🚀 Run Locally
No build step required — it's a single static file.
```bash
git clone <your-repo-url>
cd <repo-folder>
open index.html   # or just double-click the file
```
